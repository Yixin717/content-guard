### 补录 SOP

1. 登录小红书，打开规则中心对应页面
2. 截图（整页长图 + 关键段落放大图），存到本目录，命名 `诱导互动规范.png`
3. 把条款原文（逐字）粘贴成 `.md` 存档
4. 把 `rules.csv` 里该规则的 `status` 改为 `platform_official`、`source_url` 改为存档相对路径
5. 跑 `python3 scripts/verify_rules.py` 确认通过

> 平台规则是前端渲染 + 随时改版，**链接本身不构成证据**。只有「截图 + 逐字原文 + 存档日期」才是能在面试里当场翻出来的东西。
