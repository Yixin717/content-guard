# UI 风格落地说明（基于 Notion 风格参考）

> 输入：`DESIGN.md`（Notion 风格参考，营销站体系）
> 状态：**待补 4 类参考后定稿**；本文件说明"哪些能用、哪些要改、还缺什么"
> 原则：**保留它的气质，改造它的语法。** 营销页的色彩法则不能直接搬进高密度工作台。

---

## 1. 这份参考是什么

一句话：**暖纸质感 + 单一蓝色主操作 + 用彩色卡片做节奏 + 发丝级描边 + 无阴影无渐变。**

核心可迁移的 5 条：

1. 画布用暖白 `#f6f5f4`，卡片用纯白 `#ffffff` —— **这个层级不能反**
2. 主操作只有一种颜色（蓝 `#0075de`），其余动作一律 ghost / text
3. 分隔靠 **1px 描边 `rgba(0,0,0,.08)`**，不靠阴影
4. 文字层级靠**同一个黑色的透明度**（100/95/60/40），不是靠加新颜色
5. 圆角只有两档：卡片 12px、按钮 8px；胶囊 9999px 只给标签

这 5 条我全部接受，并且它们恰好解决了我们"工具型高密度"的两个难题：**怎么在不加线条和阴影的情况下分区**、**怎么让彩色不干扰阅读**。

## 2. 必须改造的三处（营销页 → 工作台）

| 参考里的做法 | 为什么不能直接用 | 我们的改法 |
|---|---|---|
| 巨型标题 54–96px、负字距 -2~-4.6px | 工作台最长的一行标题是 22px；96px 根本用不到 | **不用 display 档**；最高只到 22px（面板标题）/ 28px（页面标题）。负字距只用在 ≥24px 的拉丁字符 |
| 区块间距 80px、卡片内边距 24px | 80px 是营销页的呼吸；工作台会让一屏信息量掉一半 | 区块间距 16–24px，卡片内边距 16–20px；**密度档从 comfortable 改为 compact** |
| 大面积彩色卡片（黄/珊瑚/天蓝）铺满页面 | 在营销页是"节奏"，在编辑器里会**抢夺文字注意力**，且与严重度颜色冲突 | **把彩色收进 3 个地方**：入口页背景块、空态/结果摘要卡、统计卡片。**工作台三栏保持近单色** |

### 一条容易被忽略的 CJK 规则

参考里的负字距是为拉丁字母设计的。**中文不要套用**——中文字面本就方正，再加负字距会粘在一起。

- 拉丁：≥24px 可用 `-0.02em ~ -0.03em`
- 中文：一律 `0`，最多 `-0.01em`
- 中英混排：把字距加在包含拉丁的节点上，不要加在整段

## 3. Token 映射（保留 / 改写 / 新增）

### 3.1 直接沿用

| 用途 | 值 |
|---|---|
| 页面画布 | `#f6f5f4` |
| 面板/卡片 | `#ffffff` |
| 主操作 | `#0075de`（仅每屏一个） |
| 次级操作 | `#e6f3fe` 底 + `#0075de` 字 |
| 正文 | `#000` 60–70% 或 `#615d59`（暖灰） |
| 描边 | `rgba(0,0,0,.08)` |
| 圆角 | 卡片 12 / 按钮 8 / 标签 9999 |
| 动效 | 200ms ease |

### 3.2 改写

| 用途 | 参考 | 我们 |
|---|---|---|
| 面板分区 | 卡片浮在画布上 | 三栏**平铺**，用 1px 竖线分隔，不做卡片投影（工作台不是卡片流） |
| 顶栏 | 64px + 轻微阴影 | 48px + 底部 1px 线，**不加阴影**（阴影只给抽屉） |
| 正文行高 | 16px / 1.5 | **16px / 1.8**（中文长文需要更松，1.5 会挤） |
| 正文字宽 | 无限制 | 单栏 ≥34 字、≤42 字（约 560–700px），超了加内边距 |

### 3.3 新增（参考里没有，但我们必须有）

| 用途 | 值 | 说明 |
|---|---|---|
| 严重度·高 | `#e32d14`（vermillion，取自参考调色板） | 配图标 + 文字标签，**不能只靠颜色** |
| 严重度·中 | `#e89d01`（saffron） | 同上 |
| 严重度·低 | `#757575`（stone） | 低危用中性色，反而更醒目 |
| 违规高亮（正文） | 底 `#fdeceb` + 左侧 2px `#e32d14` + 底部细下划线 | 三通道：底色/边线/下划线，色弱也能认 |
| 悬停描边 | `rgba(0,117,222,.35)` | 与点击选中区分 |
| 选中态 | 底 `#e6f3fe` + 左 2px `#0075de` | |
| diff 删除 | 底 `#fdeceb`、字 `#b42318`、删除线 | **参考调色板里没有绿色**，diff 增色必须新增 |
| diff 新增 | 底 `#e7f6ec`、字 `#067647` | 同上 |
| 聚焦环 | `0 0 0 2px rgba(0,117,222,.35)`，offset 2px | 键盘可达性 |
| 等宽（规则 id / 数字） | `ui-monospace, SFMono-Regular, Menlo` | `ABS-004` 要对齐 |
| 中文正文字体 | `-apple-system, "PingFang SC", "Noto Sans SC", sans-serif` | 参考的 Inter 不含中文，中文会自动回落 |
| 表格行高 | 表头 32px、行 44px、hover 底 `#faf9f8` | 历史页专用 |
| 骨架屏 | `#eeeceb` 起，200ms 呼吸 | 参考未定义 |

## 4. 色彩纪律（这是"多元但不像 AI slop"的关键）

参考最值钱的一句是：**"#0075de 是唯一的填充按钮颜色，色彩多样性属于卡片背景"**。

翻译到工作台：

| 位置 | 允许的颜色 |
|---|---|
| 入口页 | 暖纸底 + 一张彩色卡片（黄或珊瑚）+ 蓝色主按钮 |
| 工作台 | 近单色：纸 / 白 / 墨 + **仅**严重度色 + 高亮色 + 主按钮蓝 |
| 历史页 | 单色 + 状态标签色 |
| 规则页 | 单色 + 三档状态色（verified/official/pending） |
| 空态/结果摘要 | 可放 1 张彩色卡片（这是"创造性"的出口） |

**禁止**：给每个面板换底色、用彩色区分三栏、在列表里用渐变、给卡片加阴影。

## 7. 三个要你拍板的决定

1. **严重度用参考里的配色（vermillion / saffron / stone），还是换成更"警报感"的红？**
   我倾向保留参考色（更统一），但 high 配一个实心三角图标强化。
2. **工作台要不要保留一张彩色卡片？**
   我倾向：只在"结果摘要"（改写前后对比的总结卡）用一张，其余近单色。
3. **空态用不用手绘角色标记？**
   用 1 个能显著提升"有人味"，但会增加一点工作量；不用也不会难看。
